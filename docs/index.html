Lead story · Experiment 001

Checking first wasn’t enough

An AI refund agent remembered that an order could be refunded. Someone refunded it a moment after the agent checked, and the agent refunded it again. I tried four ways to stop that.

If the answer changed a moment after the agent checked, the wrong refund still went out. Checking first, even when it was required, let 1 of 6 wrong refunds slip by.

Checking again at the moment of refunding stopped every wrong refund in this test.

The catch: no method gave more of the fair refunds. Each one refused a fair refund once, for a different reason.

I tested the safety net around an AI agent, not the AI itself. A simple rule plays the agent.

How I work

I pick one question from a research paper. I build the smallest test that can answer it, and write down what I expect before I run it. Then I run it, save the results, and explain what they do and don’t show. Everything is on GitHub so anyone can check it.

About

This is where I learn about AI by building small things. I’m most interested in the places where AI safety comes down to ordinary software: keeping data up to date, and making sure rules are checked at the right moment.

I used AI tools to help: ChatGPT and OpenAI Codex for the experiment, Claude Code for this site. I choose the questions, decide what to test, and check the results.
