Latest: Experiment 001 · September 2026

What stops a system from acting on old information?

An app remembered that a worker was allowed to take a shift. That changed, and the app booked them anyway. I tried four ways to stop it.

  • Checking first wasn’t enough. If the answer changed a moment after the check, the bad booking still went through.
  • Checking again while saving stopped it, every time in this test.
  • The catch: no method booked more of the right workers.

How I work

I pick one question from a research paper. I build the smallest test that can answer it, and write down what I expect before I run it. Then I run it, save the results, and explain what they do and don’t show. Everything is on GitHub so anyone can check it.

About

This is where I learn about AI by building small things. I’m most interested in the places where AI safety comes down to ordinary software: keeping data up to date, and making sure rules are checked at the right moment.

I used AI tools to help: ChatGPT and OpenAI Codex for the experiment, Claude Code for this site. I choose the questions, decide what to test, and check the results.
